# Orbit

**Orbit** is a lightweight browser extension designed to make everyday browsing more productive. It brings quick access to your favorite websites, link organization, and web content into one centralized homepage, alongside an integrated chat interface.

## Features

- **Quick Access** – Save your frequently visited websites for easy access.
- **Drag-and-Drop Organization** – Rearrange your saved websites to customize their order.
- **Persistent Storage** – Your Quick Access items and their ordering are saved locally.
- **Search Interface** – Access search directly from the Orbit homepage.
- **Instant Chat** – An integrated chat interface for interacting with prompts.
- **Prompt Shortcuts** – Quickly select actions such as:
  - Project Idea
  - Explain
  - Summarize
  - Translate
  - Generate Code
- **Favicon Support** – Display website icons, with fallback handling for unavailable favicons.
- **Minimal Interface** – A dark, distraction-free homepage designed for everyday use.

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/muhammadazandev/orbit.git
   ```

2. Open Chrome and navigate to:

   ```text
   chrome://extensions
   ```

3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the Orbit project directory.

## Usage

After installation, open a new tab or access Orbit through the extension.

Use the homepage to access saved websites, organize Quick Access, and interact with the available search and chat features.

## Project Status

Orbit is a personal browser-extension project. Its initial feature set is implemented and functional.
